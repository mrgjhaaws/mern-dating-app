# 01/15 — Project Overview and Final Application

> **Goal:** Build a modern swipe-style dating web app with **MongoDB, Express.js, React and Node.js (MERN)** and deploy it.

## What will you learn?
- Build a full-stack Dating Web App with the MERN stack
- Create a swipe-style interface and connect it to a backend API
- Store user profiles in MongoDB
- Deploy the app

## Why build this project?
- Learn to build a real-world, interactive app
- Understand full-stack development with MERN
- Work with a database, APIs and modern UI components
- Practice deployment and make the app live
- Build a strong portfolio project

## Key features
| Feature | Description |
|---|---|
| Swipe-style cards | Like, dislike and explore profiles |
| User profiles | Display images and information |
| Interactive buttons | Like, dislike and super-like actions |
| MongoDB database | Store and manage user profiles |
| REST API | Fetch profiles from the backend |
| Deployment | Backend + frontend published online |

## MERN technology stack
| Letter | Technology | Role |
|---|---|---|
| **M** | MongoDB | NoSQL database that stores user profiles |
| **E** | Express.js | Backend framework to build REST APIs |
| **R** | React | Frontend library for the UI |
| **N** | Node.js | Runtime environment that runs the backend |

## Project flow (the 5 big steps)
1. **Build the React frontend** – header, dating cards, buttons
2. **Set up Node.js & Express backend** – API routes to fetch profiles
3. **Connect MongoDB Atlas** – store profile data in the cloud
4. **Integrate frontend and backend** – fetch real data and show it
5. **Deploy the app** – backend and frontend go live

## What you will have at the end
A fully functional, deployed Dating Web App with real data, built with the MERN stack and ready to show in your portfolio.
